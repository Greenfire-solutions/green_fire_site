Step 2

Make your business folder

10 minutes

This folder is your AI's brain. Everything it knows about your business comes from what you put in here. Messy is fine. More is better than tidy.

Only you can do this part Do it

  1. Go to your Desktop. Right click (or two-finger click) an empty spot and choose New Folder.
  2. Go to your Desktop. Right click an empty spot, choose New, then Folder.
  3. It appears as untitled folder with the name ready to type over. Tap Copy name, then paste (Command + VCtrl + V) and press Enter. The name must be exactly: Your Business
  4. Drag copies of everything about your business into it: plans, price lists, menus, flyers, spreadsheets, notes, logos, photos, videos, and old emails you saved. From Google Drive or Dropbox, download them first, then drag them in.
  5. Do not sort anything. Your AI will organize it for you later.
Leave out passwords, bank statements and private customer records.

Step 5

Install Claude Code with one paste

Turn on Claude Code

5 minutes

One paste, then wait a few minutes. The line below installs Claude Code and sets it up in one go.

Two clicks. The Claude app already includes Claude Code, you just switch it on.

Only you can do this part Do it

  1. Tap Copy, click inside Warp, paste (Command + V), and press Enter.
curl -fsSL https://claude.ai/install.sh | bash; grep -qs '.local/bin' ~/.zshrc || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc; export PATH="$HOME/.local/bin:$PATH"; claude --version
  1. Wait up to 5 minutes. You may see a yellow note saying not in your PATH. Ignore it, the line already fixed that. You are done when the very last line says something like 2.1.3 (Claude Code).
  2. Type claude and press Enter. If it first asks you to pick colours or a look, just press Enter. When it asks how to log in, pick Claude account with subscription (use the arrow keys to move, then Enter). Your browser opens: click Authorize, then come back to Warp. Press Enter through any welcome notes.
  3. When Claude says hello, type /exit and press Enter. Done.
  1. Open the Claude app and sign in.
  2. In the sidebar on the left, click Code.
  3. If it asks to set up or download Claude Code, click yes and let it finish.
  4. You are done when you see a box asking you to choose a folder.
Stuck? Try these in order

1. It says "command not found: claude". Close Warp completely (Command + Q), open it again, type claude.

2. Still not found. Paste this, press Enter:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc; echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bash_profile; source ~/.zshrc; claude --version

3. The install itself failed (red error). Install Node first from nodejs.org (the big LTS button, click through the installer), close and reopen Warp, then paste:

mkdir -p ~/.npm-global && npm config set prefix ~/.npm-global && echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc && export PATH="$HOME/.npm-global/bin:$PATH" && npm install -g @anthropic-ai/claude-code && claude --version

4. Still stuck. Take a screenshot (Command + Shift + 4) and send it to Jordan. We fix it together in five minutes.

No Code tab: update the app (Help, then Check for Updates) and make sure your plan says Pro.

It says Git is missing: install Git from step 4, then restart the computer.

Still stuck: press Windows + Shift + S to screenshot it and send it to Jordan.

From here on, Claude can fix things for you. Whenever something goes wrong, you can just tell Claude what you see.
Step 6

Open Claude inside your folder, on full power

3 minutes

This starts Claude inside Your Business, on the strongest model (Opus), in the mode where it works without stopping to ask permission for every little thing.

Do it

  1. Copy this line, paste it into Warp, press Enter. It makes a shortcut so from now on you only ever type ai.
  1. Type ai and press Enter.
  2. It asks if you trust this folder: press Enter for Yes. It asks about bypass permissions mode: the answer No is selected first, so press the down arrow once to Yes, I accept, then Enter.
  3. You will see the word dangerously in the line. That is just the technical name for full power mode. It is how the pros run it.
  4. Type /model and press Enter. It should say Opus. If not, pick Opus from the list.
  1. First switch on full power once: open Settings, then Code (on some versions it is called Claude Code), and turn on Allow bypass permissions mode.
  2. Click Code in the sidebar. Under the message box, click the first button and choose Local. Click the folder button next to it, choose Open folder, and pick Your Business on your Desktop.

  4. Find the mode menu (it probably says Manual) and choose Bypass permissions.
  5. If Windows put your Desktop inside OneDrive, that is fine. Just tell Claude when it asks.
Full power means Claude acts on its own. That is what makes it fast. The build prompt in step 11 tells it the rules: never delete your originals, never spend money, never send or post anything without your yes.

Step 8

Give Claude hands: the browser and your computer

5 minutes

The Claude in Chrome extension lets your assistant open websites, fill forms and check its own work. Then you switch on the permissions it needs to use your computer.

Do it

  1. Use Google Chrome (get it here if you do not have it). Tap Add the extension, click Add to Chrome, and sign in with your Claude account.

  5. In the Claude app, open Settings, find This computer, then System, and turn on Enable computer use.
